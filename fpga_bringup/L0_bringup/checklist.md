| 1 | 文件 `bringup_s2c.bin` | `0x80000000` | 3608 B |

第 2 项**不是文件，是往那个地址写一个立即数**。别漏 —— 它是整套设计的支点：
程序会把它读回来比对，这是唯一能反证"PCIe 后门写 DDR 真的生效了"的手段。
没有它，"PCIe 没写进去"和"程序崩了"两种情况完全分不开。

## 二、放开复位

> ⚠ **反复换镜像时特别注意。** 本核有 32 KB L1I，与 D-cache 之间不自动保持一致。
> host 经 PCIe 写镜像对 CPU 来说属于"动态加载指令"。若走软复位（不断电），
> I-cache 里可能还留着**上一个镜像**的指令，CPU 会接着跑旧程序 ——
> 现象是"明明重新烧了，行为却一点没变"，调试时越反复越容易撞上。
>
> `start.S` 开头已经放了一条 `fence.i` 兜底。但如果遇到无法解释的
> "改了没生效"，**先断电重来再怀疑代码**。

## 三、读回判读

**先看这一个**：

| 地址 | 期望值 | 含义 |
|---|---|---|
| `0x87F0001C` | `0x00000000` | **FAILMASK。只有它为 0 才算通过** |

⚠ **不要只看 STATUS**。软失败之后程序会继续跑，STATUS 会被后续阶段覆盖，
最终可能停在一个看起来正常的值上。判定通过与否一律看 FAILMASK。

然后逐项核对：

| 地址 | 期望值 | 含义 |
|---|---|---|
| `0x87F00000` | `0xB00000AA` | STATUS：全部通过 |
| `0x87F00004` | `0x00000080` | vlenb = 128 字节（VLEN=1024 bit） |
| `0x87F00008` | `0x42000000` | AME 自测 = 32.0f |
| `0x87F0000C` | 任意 | 性能采样周期数（低 32 位） |
| `0x87F00010` | 任意 | 同上（高 32 位） |
| `0x87F00014` | `0x000003E8` | 采样次数 = 1000 |
| `0x87F00018` | `0x00000080` | mtilem 回读 = 128 |
| `0x87F00084` | `0x5A5AC3C3` | 程序读到的 magic |

串口 `0x20100000`（16550，8N1）上有完整日志，六步逐行打印。
**串口没输出不代表失败** —— 优先看 mailbox。

## 四、故障速查

| 现象 | 多半是什么 | 怎么办 |
|---|---|---|
| STATUS 读到 `0` 或一直不变 | CPU 没跑起来 | 查复位是否真的放开、时钟是否有、镜像是否真写进了 `0x80000000` |
| STATUS = `0xB0000010` 后不动 | 卡在串口 | 串口寄存器可能不响应；见下一行 |
| mailbox 在推进但串口一个字都没有 | 波特率没配 | 重新编译时加 `-DUART_NEEDS_INIT -DUART_DIVISOR=<值>`，分频值 = UART 输入时钟 /(16×115200)，需向硬件确认输入时钟 |
| FAILMASK 的 bit3 置位（`0x8`） | **PCIe magic 不符** | 确认第 1 步的第 2 项写了；读 `0x87F00084` 看程序实际读到什么。读到 0 说明那次写入没落到 DDR |
| FAILMASK 的 bit4（`0x10`） | RVV 没使能或 VLEN 不对 | 读 `0x87F00004`，应为 128 |
| FAILMASK 的 bit5（`0x20`） | AME 结果不对 | 读 `0x87F00008`，应为 `0x42000000` |
| 串口打出 `*** TRAP ***` | 发生异常 | 记下 mcause/mepc/mtval，用 `riscv-unknown-elf-addr2line -e deliverables/fpga/bringup_s2c.elf <mepc>` 定位 |

## 五、通过之后

第六步会回填性能采样数据，这是**上板才能拿到、之前只能靠猜的数**：

```
每次满 tile mfmacc 的周期数 = CYCLES / ITERS
decode 一个 token 需约 145500 次 mfmacc
  => 每 token 耗时 = 145500 × 周期数 / 50 MHz
```

之前的估算区间横跨一个数量级（0.2 秒到 3 秒每 token），拿到这个数就收敛了，
demo 的呈现方式才有依据。**把 CYCLES 和 ITERS 两个值发我，我来算。**
