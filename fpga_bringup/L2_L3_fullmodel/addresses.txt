# S2C 后门加载地址表（由 src/bsp/board.h 生成，勿手改）
# 生成时间 2026-09-04 11:08

## L0
bringup_s2c.bin      0x80000000
PCIe 自证 magic    0x87F00080   (32 位立即数 0x5A5AC3C3，不是文件)

## L2 / L3 / L4   （三者地址相同，区别只在用哪个目录的文件）
qwen3_s2c.bin        0x80000000
w.bin                0x88000000
tok.bin              0xD0000000   (L3/L4 才需要；L2 不加载它)

!! qwen3_s2c.bin 与 w.bin 必须取自同一个目录 !!
   固件把权重总长编进了二进制并严格核对，跨目录混用会在启动时
   报 QWEN3_ERR_SIZE 停下（不是 trap，串口有明确错误行）。
   L2_L3_fullmodel/ = row 布局   L4_demo/ = tile-major 布局

## 授时（可选；不做也能跑）
EPOCH                0x87F00014
   放开复位前往这里写一个 uint32：当前 UTC 秒（date +%s）。
   固件加 8 小时得北京时间，提示符显示为 [2026-09-03 14:23:05]。
   不写也能跑 —— 读到 0 就退回显示开机时长 [开机 00:12:34]，
   不会出现 1970 年。板上没有 RTC，时间只能这样来。

串口 (16550)       0x20100000
